Backup sync program using Windows ROBOCOPY.  Designed to be free, simple and fast, in the mold of MS SyncToy (not generally now available), Perfect Backup, Cobian Reflector and others (increasingly hobbled free versions).

Installer: https://github.com/litdev1/RoboSync/releases/download/Version1.0/Setup.exe

Installer may request .Net runtime to also be installed.
